THE INVISIBLE WORKFORCE — STREAMLIT PROJECT

Run locally:
1. Install Python 3.10 or later.
2. Open a terminal in this project folder.
3. Install dependencies:  pip install -r requirements.txt
4. Start the dashboard:  streamlit run app.py

The two original Excel workbooks are included in the data folder. Keep the
folder structure intact. The app.py file automatically searches the project
folder and its data subfolder for the workbooks.

DESIGN UPDATE
- The Explore the Data section and the underlying calculations are retained.
- The Story section includes a real Pexels photograph (not AI-generated).
- Research questions and problem framing use simple icons.
- Key Findings includes a zero-based horizontal comparison chart for the
  women's and men's labour-force participation rates, plus visual icon cards.
- The From Evidence to Action section includes a five-step visual roadmap.
- The overview begins with an executive summary.
- No AI-generated pictures are included. Other visual elements are built from
  native HTML/CSS and Plotly charts.
